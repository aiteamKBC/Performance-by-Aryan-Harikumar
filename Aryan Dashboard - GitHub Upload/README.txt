Aryan Performance Dashboard

Open index.html in a modern browser. This standalone dashboard includes the captured learner data and wellbeing case history.

Keep this repository PRIVATE: it contains identifiable learner performance, wellbeing and safeguarding records. This package does not configure GitHub Pages or publish the dashboard.

Browser-local changes (RAG categories, follow-up plans and gateway edits) are saved only in the browser where you make them. Use the dashboard backup/export controls to retain those changes. Existing browser edits are not embedded in this source package.

Snapshots: performance and Aptem data 23 October 2026; wellbeing data and notes 26 October 2026. No live connection or automatic refresh is configured.
